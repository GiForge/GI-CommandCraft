# 📂 Dual Pane File Manager

Un file manager avanzato per Android ispirato ai classici gestori a doppio pannello, progettato per fornire operazioni rapide su file locali, condivisione, archivi compressi, rete LAN/SMB e strumenti integrati per utenti avanzati.

# 📖 Panoramica

L'applicazione implementa un'interfaccia **Dual-Pane** pensata per semplificare la gestione dei file su smartphone Android, consentendo operazioni rapide di copia, spostamento, compressione, condivisione e navigazione di risorse locali o remote.
